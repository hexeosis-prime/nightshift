# Starter project

`nightshift init <folder>` copies this folder. It is a small, complete example: one character, two worlds, eight shots
covering every mode, a song brief and a placeholder lyric sheet. Replace the content, keep the shapes.

| file | |
|---|---|
| `project.json` | settings; only what differs from the defaults |
| `canon.json` | the character (identity words, wardrobe per framing and world, never-list, sheets), worlds, defaults |
| `shots.json` | the shot list; field reference in docs/shots.md |
| `song/caption.md`, `song/lyrics.txt` | the song brief and lyric sheet for MiniMax Music 3; or put your own `song/song.mp3` here |
| `refs/` | character sheets (`lead_real.png`, `lead_stage.png`): make these first |
